
# Jibban - Personal Expense Tracker

A command-line application to track daily expenses, written in Python.

## Features

- Add expenses
- Show all expenses
- Generate expense reports
- Search and delete expenses
- Generate monthly reports
- Run automated tests

## How to run

    python main.py

## How to run tests

    python test.py

## What I learned

- Python functions and classes
- Object-oriented programming
- Working with dates
- Automated testing with unittest
- Git version control
